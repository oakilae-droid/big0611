# 김해원 개인 포트폴리오 웹사이트 제작 작업 내용

`naena/프롬프트.txt` 파일에 기재된 명세와 요구사항을 바탕으로 제작한 고품격, 모던 스타일의 개인 포트폴리오 웹사이트입니다.

## 🛠️ 기술 스택 및 구조
- **HTML5**: 웹 표준 시맨틱 태그 및 검색 최적화(SEO) 반영.
- **CSS3 & Bootstrap 5**: 모바일-데스크톱 반응형 그리드 적용, 글래스모피즘(Glassmorphism) 스타일 디자인, 미려한 그라데이션 적용.
- **JavaScript (Vanilla JS)**: 네비게이션 스크롤 동작 활성화, Intersection Observer를 활용한 부드러운 스크롤 페이드인 애니메이션, 연락처 폼 유효성 검사.
- **아이콘 라이브러리**: Devicon(개발 스택 아이콘) 및 Bootstrap Icons 적용.
- **파일 구조**:
  - `naena/index.html` : 전체 포트폴리오의 구조와 컨텐츠 (원페이지 형태)
  - `naena/css/style.css` : 컬러 토큰 정의 및 디테일한 커스텀 프리미엄 CSS 스타일시트
  - `naena/js/main.js` : 브라우저 동작 제어 및 모바일 네비게이션 반응을 위한 스크립트

## 📌 주요 작업 및 수정 내용 (섹션별 정리)

### 1. 첫 번째 섹션 (HOME / HERO)
- **개인 사진 원형 배치**: 생성형 AI로 생성한 세련된 남성 소프트웨어 개발자 애니메이션 캐릭터 이미지(`images/profile.png`)를 원형 테두리와 입체적인 네온 글로우 효과와 함께 배치하였습니다.
- **이름 영문 슬라이딩 텍스트**: 이름 표기를 이탤릭 경사 효과를 지닌 영문만(`Kim Hae-Won`) 노출하도록 수정하여 세련미를 더했습니다.
- **타이틀 및 소개 수정**: 기존 "빅데이터 분석 수강생" 문구를 영어 직무명인 `Big Data Analyst & Full-Stack Developer`로 고도화해 표기했습니다.
- **SNS 아이콘 스타일링**: 하단 링크 밑줄을 완벽히 제거하고 호버 시 부드러운 원형 배경 전환 애니메이션을 추가했습니다.
- **네비게이션 메뉴**: 상단 헤더에 고정(Fixed) 형태로 위치가 지정되어 있고 클릭 시 해당 섹션으로 부드럽게 스크롤됩니다.

### 2. 두 번째 섹션 (ABOUT / RESUME & EDUCATION)
- **영문 제목 유지**: 섹션 타이틀은 각각 `My Resume`와 `Education`으로 영문 표기하였습니다.
- **한글 폰트 적용**: 미려한 산세리프 한글 본문 가독성을 위해 구글 폰트의 `Noto Sans KR` 폰트와 영문 `Outfit` 폰트를 조합하였습니다.
- **교육 이력 데이터 추가 & 정렬**: 
  - 최근 날짜 순서(역순)로 교육 내용을 정렬했습니다.
  - 가상의 이력으로 스마트 웹/앱 개발자 과정(2024~2025) 및 대학 전공(2022~2024) 2건을 추가하였습니다.
- **프로필 레이블 영문/내용 한글**: `Name`, `Phone`, `Email`, `GitHub`, `Address` 등 레이블은 영문을 유지하되 입력 값들은 한글로 노출시켰습니다.

### 3. 세 번째 섹션 (SERVICES)
- **교육 내용 기반 전면 수정**: 수강 중인 "생성형 AI와 챗GPT를 활용한 빅데이터 분석 & 자동화 시스템 구축 과정"을 기반으로 실무 비즈니스 영역을 도출하여 4개의 카드로 고안했습니다.
  - *Big Data & Visualization* (빅데이터 처리/시각화)
  - *Generative AI & LLMs* (생성형 AI 및 챗GPT 응용 연동)
  - *Workflow Automation* (크롤링 및 업무 자동화 구축)
  - *Full-Stack Web Dev* (React/Spring Boot 풀스택 웹 서버 개발)
- **헤드라인 영어, 상세 본문 한글** 구성으로 가독성을 대폭 향상했습니다.

### 4. 네 번째 섹션 (SKILLS)
- **Skills 타이틀 통일**: 불필요한 하위 카테고리 분류(Frontend 등)를 완전히 제거하고 단일 'Skills' 섹션으로 구성했습니다.
- **주황색 바 및 백분율 제거**: 평면적이고 고정관념을 주는 프로그레스 바 대신 세련된 스택 아이콘 카드 형식으로 수정했습니다.
- **6개씩 가로 배치**: 데스크톱 화면에서 가로 6개씩 3줄로 깔끔하게 떨어지는 반응형 그리드 레이아웃을 도입했습니다.
- **Devicon 적용**: 각 기술을 나타내는 로고(HTML5, React, Python, ChatGPT 등)를 풍부하게 삽입했습니다.

### 5. 다섯 번째 섹션 (TEAM PROJECTS)
- **제목 영어화**: `Team Projects`로 제목을 수정했습니다.
- **주제 맞춤형 이미지**: 농작물 생육, 주차관제, 부동산 매물 추천, AI 지능형 학습 등 프로젝트 주제에 부합하는 Unsplash 고품질 이미지를 매칭했습니다.
- **호버 패딩 & 텍스트 크기 조정**: 카드 이미지 호버 시 오버레이 화면에 부드러운 패딩과 축소 정렬된 상세 폰트 요약 설명이 노출됩니다.
- **네이버 이동 연동**: 프로젝트 전체 카드 클릭 또는 '더보기' 클릭 시 새 탭에서 `https://www.naver.com`으로 리다이렉트되도록 설계했습니다.

### 6. 여섯 번째 섹션 (MY CREATIONS)
- **개인 작품으로 전면 수정**: 제목을 `Personal Creations`로 구성하고 요약 설명을 한글로 작성했습니다.
- **가상의 개인 작품 3종 추가**: 
  1. *AI 뉴스 요약 및 자동 메일링 서비스*
  2. *개인 금융 가계부 & 소비 패턴 시각화*
  3. *실시간 주식/코인 알고리즘 자동매매 봇*
- **좋아요/조회수 제거**: 요청에 따라 SNS형 좋아요 하트 아이콘 및 조회수를 제거하고 깔끔한 더보기 형태(`더보기`)로 네이버 링크와 연동했습니다.

### 7. 일곱 번째 섹션 (HIRE ME!)
- **설명글 한글화**: `Hire Me!` 문구 하단 안내 본문 텍스트를 정교한 한글 비즈니스 제안서로 전면 번역 및 수정 적용했습니다.

### 8. 여덟 번째 섹션 (CONTACT)
- **양측 분할 레이아웃 구현**: 왼쪽에 신뢰감을 주는 비즈니스 Unsplash 작업 공간 이미지를 배치하고, 우측에 입력 폼을 두는 콤팩트한 뷰 포트를 구현했습니다.
- **한글 플레이스홀더**: 입력 상자 안내 텍스트를 모두 한국어 가이드 문구로 변경했습니다.
- **Web3Forms 연동**: 폼 전송 시 실제 사용자 이메일로 메일이 발송되는 무료 Web3Forms API 구조를 구현했습니다. (폼 최상단 hidden 필드의 `YOUR_ACCESS_KEY_HERE`를 발급받은 실제 엑세스 키로 대체하면 작동합니다.)
- **제목 및 크기 정렬**: 제공된 가이드라인과 동일하게 제목 배치와 입력 폼 카드의 크기가 일정하도록 조율했습니다.

### 9. 푸터 영역 (FOOTER)
- **저작권 표기 갱신**: 2026년 기준 김해원 소유 저작권 표기(`© 2026 김해원. All rights reserved.`)로 갱신 완료했습니다.

## 🚀 확인 및 실행 방법
1. 브라우저로 `naena/index.html` 파일을 엽니다.
2. 각 메뉴 클릭 시의 부드러운 스크롤과 마우스 호버 시의 글래스모피즘 오버레이 뷰, 다이나믹 카드 애니메이션을 즐기실 수 있습니다.
3. Contact 폼에 내용을 작성하고 전송하면 Web3Forms를 타고 발송 동작이 구동됩니다.
