## 3. 기술 스택

### 3.1 프론트엔드

- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5
- Flexbox Layout

### 3.2 백엔드

| 구분 | 기술 |
|------|------|
| 런타임 | JDK 21 |
| 프레임워크 | Spring Boot 3.5.x |
| 템플릿 | Thymeleaf |
| WAS | Tomcat 10.1 |
| DB | MySQL 8 |
| 빌드 | Gradle |

### 3.3 Spring 의존성 (DI)

- `spring-boot-starter-web`
- `spring-boot-starter-security` (BCrypt)
- `spring-boot-starter-thymeleaf`
- `mysql-connector-j`
- `lombok`
- `spring-boot-starter-jdbc` (JdbcTemplate)

### 3.4 배포

- **DB:** TiDB (MySQL 호환 분산 DB)
- **서버:** Render 또는 AWS EC2

### 3.5 RPA + AI (Python)

| 패키지 | 용도 |
|--------|------|
| NumPy | 수치 연산 |
| Pandas | 데이터 전처리·분석 |
| Matplotlib | 기본 시각화 |
| Seaborn | 통계 그래프 |
| Plotly | 인터랙티브 차트 |
| Requests | HTTP API/웹 요청 |
| BeautifulSoup | HTML 크롤링 |
| scikit-learn | ML 예측 모델 |

## 6. PPT 재생성 방법

```bash
# python-pptx 설치 (최초 1회)
pip install python-pptx

# 프로젝트 폴더에서 실행
cd 프로젝트
python create_ppt.py
```

실행 후 `부동산_웹플랫폼_제작결과_발표.pptx` 파일이 생성된다.
